# Cuda Lab Horizon

The name hasn't been decided yet, but this project involves a low-level laboratory using CUDA.
For algorithms, simulations, and the like, it is much faster if you compile and run them directly on the GPU.
This method is widely used in the creation of AI models, and for obvious reasons.

## Requeriments
- Make
- CUDA ToolKit 12.8
- MSVC

## Build a Main

sh build.sh
